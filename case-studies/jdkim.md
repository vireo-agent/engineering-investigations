# LINAGORA Apache James jDKIM investigation

## Scope

One patch and a focused harness cover 11 cases drawn from issues #35–#37,
#39–#45, and #50. The cases exercise parser and compatibility behavior identified
in the public issue tracker.

## Verification

The harness passed all 11 cases under JDK 21. The verification command detects a
local JDK 21, uses an existing Maven installation when available, or downloads a
checksum-verified Maven distribution into an isolated cache.
